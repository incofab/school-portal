# How to Record School Results

## Introduction

Welcome to EduManager. In this walkthrough, we’ll follow a complete school-results workflow from start to finish. You’ll see four practical ways to record results: one student at a time, an entire class, an Excel workbook, and a completed CBT exam. We’ll also review the result summaries and result sheets that help staff check their work.

## Sign In and Results Area

We’ll start by signing in with the school administrator account. From the dashboard, open Subject Teachers. Result entry is organized around a teacher assignment, so each row connects a subject with a class. The Record Result menu gives us the two main entry choices we’ll use: Single Student and All Class Students.

## Individual Student Entry

First, choose Single Student for Result Workflow Mathematics in JSS 2 Result Recording. The form shows the selected subject, class, and teacher, then asks for the Academic Session and Term. Choose Full term so the form displays the full-term assessment workflow.

Next, search the Student field and choose Amina Result. The assessment fields are shown separately. First Assessment and Second Assessment each contribute their own component to the course result, while Exam records the end-of-term exam mark. As the values are entered, EduManager combines them into a Result and derives the Grade.

Once the assessment and exam values are ready, select Submit to save this student’s result. The Student Results table below the form provides the review point: it shows the learner, subject, assessment values, exam, combined result, and grade. This form does not include a separate comment field; comments are handled later in the term-result and evaluation workflows.

## Whole Class Entry

Now return to the same subject-and-class assignment and open Record Result again. This time, choose All Class Students. The class workflow begins with a Full Term selection, then places the learners for the subject together on one page.

Each learner has the same assessment columns and Exam field. Amina’s saved values are already visible, and David’s row is ready for entry. Enter the assessment components and exam mark for the remaining learner. Each card shows a running Total, making it easy to review the row before saving.

When the class rows are ready, choose Submit. EduManager records the changed scores, processes the class summary, and calculates the class positions. The class result can then be reviewed from the result-analysis pages.

## Excel Result Workflow

For schools that prepare scores in a spreadsheet, open Recorded Result Detail and choose Upload Results. This opens the course-level upload preview, where the teacher, Academic Session, Term, result type, and workbook are kept together. The Download action beside it provides the matching recording-sheet export options.

For this walkthrough, we’ll use Upload Class Sheet, the whole-class Excel entry point. Select the Academic Session, the First term, and the SS 1 Excel Import class. The workbook is structured with the student ID, student name, and the subject column used by the school.

Now choose the seeded demonstration workbook in the file area. After checking the class and term, select Submit. EduManager imports the course score for the matching student and updates the class result summary.

## Reviewing Results

The Student Results page is the detailed review area. It shows assessment values, Exam, the combined Result, Position, and Grade, with filters for the class, subject, session, student, teacher, and term.

Recorded Result Detail groups results by subject and class. It provides a quick view of student counts, totals, maximums, minimums, and averages.

Class Result Analysis brings the class view together. It shows the number of learners and courses, aggregate totals, averages, positions, and the current lock state. Calculation and locking are administrative processing steps, so this tutorial only explains where they are reviewed.

From the class summary, Student Results opens the term-result list. This is where staff can review each learner’s total, average, position, grade, and any available teacher or principal comments.

Finally, open the Result Sheets area. The report-style sheet presents the processed result for review and printing, including the assessment columns, exam, total, grade, position, class average, and remark. Publishing is a separate administrative decision and is not performed here.

## CBT Exam Outcome

EduManager can also use completed computer-based examinations as part of the academic result workflow. Open CBT Events and locate Result Workflow CBT Exam. The event row provides View and Exams paths.

View confirms the event details, including the class and subject attached to the exam. The Exams page shows the completed student outcome with its exam number, score, class, and Ended status. Opening the detail view lets us confirm the completed subject score before transferring it.

## Transfer CBT Results

Return to the CBT event list and choose Upload on the completed event. This opens Transfer Result Workflow CBT Exam Results. Choose the academic subject assignment for Result Workflow Mathematics in JSS 3 CBT Transfer, then check Transfer to Exam scores.

The transfer form keeps the Academic Session, Term, teacher assignment, and destination together. When those values are correct, choose Submit. The event list then marks the event as transferred, keeping the CBT outcome connected to the academic result workflow.

## Review the Transferred Score

Return to Student Results. The CBT learner’s academic row now shows the transferred value in the Exam column, and that value contributes to the combined Result and Grade.

Class Result Analysis remains the place to review the aggregate and processing state after a transfer. Check the results here before making any later correction or separate publication decision.

## Conclusion

That’s the complete result-recording workflow in EduManager. Use Single Student for focused entry, All Class Students for a class-wide entry, Excel upload for a prepared workbook, and CBT transfer when examination scores are ready. After recording, review the course results, class analysis, term results, grades, positions, averages, and result sheets so the school can make its final administrative decisions with confidence.
