# EduManager UI/UX Skill

This folder contains a repository-scoped Codex skill for auditing and improving EduManager interfaces while preserving application logic.

## Install in the EduManager repository

Copy the folder to:

```text
<edumanager-repository>/.agents/skills/edumanager-ui-ux/
```

The final structure should be:

```text
.agents/
  skills/
    edumanager-ui-ux/
      SKILL.md
```

Restart Codex only if the skill does not appear automatically.

## Invoke it

In Codex CLI, use:

```text
$edumanager-ui-ux Improve the student list page for mobile without changing its logic.
```

You can also ask Codex normally; the description is written so the skill can be selected implicitly for relevant EduManager UI/UX work.
