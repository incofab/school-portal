# EduManager specifications

The maintainers' current engineering specification set is in [`docs/specs/README.md`](docs/specs/README.md).

Start there for the architecture map, backend and frontend conventions, UI system, data model, security/access control, module map, cross-cutting workflows, testing/operations, and future Codex development checklist.

The existing browser-readable feature knowledge base remains under [`public/feature-docs/`](public/feature-docs/). Both documentation surfaces should be kept aligned with behavior changes; source code and tests remain authoritative.
